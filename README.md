# 🔐 Message Encoder & Decoder

A Python command-line application that encodes and decodes messages using a custom encryption algorithm with randomized prefixes and suffixes.

---

## 📌 Features

- 🔒 Encode plain text messages
- 🔓 Decode encoded messages
- 🎲 Randomized prefix and suffix generation
- 🔑 Supports custom encryption keys (3, 4, and 6)
- ⚠️ Input validation and error handling
- 💻 Simple command-line interface

---

## 🛠️ Technologies Used

- Python 3
- Random Module
- String Module

## 🚀 Getting Started

### Clone the Repository

```bash

```

### Navigate to the Project

```bash
cd Message-Encoder-Decoder
```

### Run the Application

```bash
python encode_decode.py
```
